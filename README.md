# ClaimFlow - Insurance Policy & Claims System

Hệ thống quản lý hợp đồng bảo hiểm và yêu cầu bồi thường (Insurance Policy & Claims System).

## Build & Test
```bash
mvn clean compile
mvn test
```

## Run
```bash
mvn compile exec:java -Dexec.mainClass="insurance.Main"
```
hoặc chạy trực tiếp class `insurance.Main`.
